# Backlinks Playbook – Hardcore SEO for osamamoussa.co.uk

Backlinks are one of the strongest ranking factors. This playbook is a **no-excuses, execution-ready** plan: prioritised list, outreach templates, UK-specific sources, and tracking so you can run it systematically.

**Canonical URL everywhere:** `https://www.osamamoussa.co.uk` (homepage) or specific page. Use the same URL on every listing.

**Don’t forget: accreditations = backlink targets.** The site already links to RCS Eng, BMA, BOMSS, AUGIS, and IFSO (footer + LogosSection). Ask each body to add his **website** to his member/profile page so they link back. That gives high-authority, relevant backlinks. Same for GMC: ensure his GMC register entry or profile links to the site if the field exists.

## Part 6: What to avoid

- **Buying links** or link packages: high risk of penalty.  
- **Link exchanges** with irrelevant sites: can be seen as manipulation.  
- **Over-optimised anchor text:** don’t make every link “Upper GI surgeon London”. Use “website”, “Mr Osama Moussa”, or natural phrasing most of the time.  
- **Spammy directories:** if the site looks like a link farm or has no real traffic, skip it.  
- **Broken or wrong URL:** always use `https://www.osamamoussa.co.uk` (with www). Test the link after adding.
